# AgentMemory 0.9.84

The dashboard reads native retrieval counts and readiness rather than empty resident search indexes. Unavailable counts remain unknown. Graph snapshots are identified as historical separately from the native graph indexes.

Recent Activity shows bounded successful session and observation writes since this service started. It does not scan the full database or claim to reconstruct historical activity.

Local viewer updates no longer request a separate update password. Loopback Host, Origin and Fetch Metadata checks, one-use update tokens, duplicate exclusion and installation prerequisites remain enforced.

This package includes the current native engine and the existing graph-job retention fixes. Application updates preserve the instance data and configuration. A storage-growth investigation remains separate from activation.

Runtime assets were compiled for this release. Tests and typechecking were not run, following the user's execution preference. Local startup health and logs are checked during activation.
