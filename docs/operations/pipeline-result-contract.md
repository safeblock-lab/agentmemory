# Pipeline structural result contract

Consolidation and temporal graph results are parsed from the captured provider response with the shared strict XML reader. Domain parsers validate the document structure, allowed attributes, required provenance, enum values, and numeric/date fields. Attribute order has no meaning. Unknown attributes, malformed nonempty content, ambiguous relationship endpoints, and missing provenance are rejected before persistence.

An explicit empty collection is a valid result only when its expected root and required collection elements are present. It remains distinguishable from a parse failure, so malformed content cannot be acknowledged as an empty result. Consolidation replays its retained raw response and does not call a provider or replace the original capture. Confidence values must use decimal notation in the supported range; blank, hexadecimal, exponent, non-finite, and out-of-range values are invalid.

Temporal work preserves the established graph-job ordinal schedule: single jobs use raw response 1, parsed result 2, apply 3, and finalization 4; grouped jobs use work unit `4i+1`, raw response `4i+2`, parsed result `4i+3`, apply `4i+4`, and finalization `4U+1`. Fresh parses use the existing parsed-result slot. Completed parent captures, deltas, callback receipts, acknowledgements, and original totals are immutable.

For a completed historical parent whose digest-verified parsed capture is exactly the legacy empty shape, repair is allowed only when the matching applied delta proves success with zero nodes and edges, its callback receipt is completed, and current source and project provenance still match. A deterministic local child captures the reparse and any generated values under its own identity. The parent retains its original result and counts; repair totals are reported separately. Invalid, stale, corrupt, nonempty, or otherwise unproven historical cases return `recovery-needed` without advancing a work manifest or deleting a page. The child uses no provider transport. Grouped recovery reads one unit at a time; a future unit without a durable captured response stops recovery without transport or page/manifest advancement.

New temporal work pages record a versioned session/project authority alongside each source fragment. Existing pages and request identities are read as captured; optional authority is not part of the source fingerprint and is added only to newly admitted pages. Older pages without authority can be repaired only when their stable observation IDs resolve uniquely to current observations whose source bytes match the captured fragments and whose current session belongs to the same project. If that proof is unavailable, recovery is required rather than guessing.
