# Automatic graph workflow recovery

This describes source integration with state::graph_automatic_recovery_v1. This unit did not compile, install, run or test a live recovery. Main owns activation and runtime effects.

The selected configured OpenAI validated-json-text provider prepares through its real existing serializer. Automatic dispatch bypasses retry/fallback/repair wrappers and uses one raw configured POST per original fresh post-COMMIT permit, redirect error, a real timeout and bounded response. It captures native response parts and the complete native reference before decoding HTTP JSON, parsing graph JSON or publishing graph changes. Complete captures are read locally after restart or lost ACKs. Missing dispatch ACKs never authorize a call; native reconciliation preserves unknown/potentially-spent evidence.

Normal service startup awaits registerGraphFunction from index. It derives immutable authority profiles from the configured provider builder/model/endpoint/options and fixed extraction system prompts. The only template placeholder is the actual frozen user prompt at value:{delta}:automatic-source, pointer /value. Profiles bind the exact parser contract, ordinary provider-response target or grouped project-work-response:v3:{unit}, and native job continuation unit selector. No credential headers enter profiles or bindings.

installGraphAutomaticAuthority writes graph-automatic-authority.json in getGraphAutomaticStateDirectory(): the ordinary CLI service setting AGENTMEMORY_DATA_DIR, otherwise ./data relative to the service cwd. This must be the parent of the real configured native State database. Deployments overriding State's file location must align this normal service configuration. Startup merges existing declarations, retains all previous profiles and rejects changed IDs; the file remains bounded to 64 KiB and32 profiles. A synced private temporary file is renamed into place. Unsafe owner/ACL or symlink/reparse configuration fails closed. Unix directory/file ownership must be service UID or root with no group/other permissions. Windows owner and every simple allow/deny ACE SID must be process user, SYSTEM or Administrators, with a non-null DACL and at most64 ACEs; broad inherited permissions are rejected. Native independently opens the fixed file and directory with protected handles through each authorization COMMIT. No public State install RPC or per-incident grant exists.

Before effects, the workflow captures the complete job input, actual source prompt, not-dispatched intent, full serialized request, source versions and parser contract. An interrupted preparation attempt is preserved until native recovery decides its disposition. Before cleanup/admission, it pauses/drains heartbeat and storage queues. It adopts the native fence and manifest identity, clears stale buffers, restores the checkpoint and drains bounded cleanup pages. Only owned incomplete derivatives are cleaned; inputs, complete captures, publication, unknown intents, costs and consumed counters remain.

A failed raw attempt becomes unknown, not a known non-dispatch. Native can admit only its bounded additional attempt. Every attempt uses a separate one-shot prepared provider object and fresh permission. Native extra-attempt exhaustion is terminal. Temporary waits use retry_after_ms as an absolute UTC timestamp, separate from deadline_ms expiration.

Legacy unknown requests are never reconstructed. Native retains the failed original and can reserve a new linked job. The new job uses complete actual captured source and current builder, skipping repeated TypeSafe gates/compaction and external local compaction. Grouped regeneration copies only remaining durable source pages and prior cursor/counts, removes the old active-unit identity and claims the first new slot against the original root's sole reserved extra attempt. Its claimed slot is durable. Subsequent untouched units are distinct original slots; exhausted slots and already-published prefixes are not reissued. The dispatcher follows the linked job until its real workflow terminal. A bounded nongrouped regeneration explicitly reports any incomplete remainder as partial.

## Backend/viewer contract

CLI data-directory creation requests mode0700. Existing Unix permissions can be restricted only for resolver source=default and an exact standard dedicated agentmemory application directory (or its selected instance), owned by the current UID, canonical without symlink aliases and outside any git tree. A no-follow directory handle must match the original device/inode before fchmod0700. Legacy cwd/data, flag/env custom directories, root/home/cwd, different owners and Windows ACLs are never migrated. No ownership changes occur.

Bootstrap failures disable only automatic authorization; they do not prevent normal memory service startup. Existing automatic jobs cannot fall through to generic external dispatch while disabled. GET /agentmemory/config/flags and every graph/build response expose graphAutomaticAvailability:{enabled:boolean,reason:string|null}. Only successful private profile installation sets enabled=true; safe fixed reasons distinguish non-private, changed, oversized/unavailable authority and unsupported provider. Failed bootstrap logs contain only the safe reason, without paths, request content or credentials. Graph/build's automatic action is null while disabled; retain the continuation and display the reason rather than scheduling recovery.

Already stopped failed jobs enter native terminal_recover during normal mem::graph-recover maintenance and dispatch reconciliation, including intents already recorded as failed. This does not remove recoveryStopped or rewrite the failed original intent, checkpoint, receipts or published prefix. The command supplies the actual leased guard and versioned job/checkpoint. Native derives the historical slot and validates retained source before returning a linked replacement or stable terminal reason. Ambiguous history has no invented root. Simple input-units/provider-response without a proven source cursor stays SOURCE_UNIT_UNPROVEN; the supported simple fallback is the proven compaction delta. Old generation source stays SOURCE_GENERATION_STALE.

Discovery spends at most four candidates per cycle and creates at most one new link. It prioritizes one actual failed job ID from the durable workflow-invocations:graph:v1:all/failures history, then advances a durable fair cursor through at most three projected job records. State projection applies before the 32 KiB page budget, excluding large prompts and continuation source IDs. Full selected candidates are read separately. Stable denials and source failures are retained under graph-automatic:terminal:{jobId}; cooldowns are reconsidered at the native absolute timestamp. No candidate is silently marked resolved because its full source cannot be read.

A validated complete historical string can produce local_replay. The replacement copies the exact versioned frozen string without HTTP decoding or a raw provider permit. job.automaticLocalReplayDelivery selects its committed delta/name; native proves the final apply receipt and byte-identical frozen source before permitting a later untouched unit. The replay consumes the same original root reservation; it does not create another API expense. A failed local delivery remains LOCAL_FAILED. Background selected recovery requires native private lineage proof of the same original project, session, source fingerprint and exact captured observations/versions; descriptive caller metadata cannot authorize a broader selection.

GraphAutomaticRecoveryView in src/functions/graph-automatic-workflow.ts is stored as job.automaticRecovery and projected by graph/build:

- version1, slotId, rootId, native state, sanitized reason.
- captured, potentiallySpent and retryAdmitted describe native evidence, not certainty of external delivery.
- deadline is attempt expiration. nextCheckAt is absolute UTC milliseconds from native retry_after_ms, or the expiration of an intended attempt; null means no supplied timer.
- replacementJobId names a different linked job, never the current child itself.
- action is continue, wait or none. A terminal original with an active linked replacement can have continue. A complete native capture can also have continue when the workflow still has untouched units.

POST /agentmemory/graph/build retains the exact opaque root continuation and projects automaticRecovery plus action:{endpoint:'/agentmemory/graph/build',project,continuation}|null. Return those exact project/continuation fields to continue or poll. Never construct IDs or replace the cursor to bypass spent state. The same source maps to its same deterministic job. After HTTP loss, retain the last confirmed state; any repeated action reconciles native state before dispatch.

Stopped history additionally projects automaticTerminalRecovery, typed GraphTerminalRecoveryView in src/functions/graph-automatic-terminal.ts: version, sourceJobId, resolution (local_replay/regeneration/terminal), reason, nextCheckAt, replacementJobId and action. This projection can legitimately have no native slot/root. It takes precedence for action/timing over automaticRecovery and follows the actual child workflow; a child capture alone never completes the original group. The viewer retains the exact original continuation and sends it to the existing graph/build route. nextCheckAt is absolute UTC milliseconds; null supplies no polling timer.

POST /agentmemory/graph/extract now whitelists observations rather than forwarding raw body. No REST/MCP endpoint/tool, KV scope or version was added. Invocation/failure accounting remains separate from workflow terminal receipts. Native capture completion alone does not declare the graph workflow published or complete.

## Provider usage accounting

Current mem::graph-recover localOnly:true is strict: it skips terminal discovery and returns no_local_apply_pending when no native apply barrier exists, or defers an unprepared checkpoint. It rechecks after normal native acquisition and only runs the captured APPLYING finishFreeze/apply path. It never reaches the extraction handler or automatic provider path. localOnly:false retains ordinary background recovery and terminal regeneration. This strict contract supersedes the historical early-driver warning that localOnly:true could enqueue automatic provider work; historical journals and outcomes are not rewritten.

Pending native apply takes priority over terminal discovery. Normal graph recovery reads the exempt control row first and skips guardless terminal job pages while control.recovery is present. It acquires an expired lease through the existing native acquire contract in the same generation; native increments the fence and preserves the recovery barrier. Job, checkpoint, manifest, captured inputs and prepared bytes are then accessed with that current guard. Extraction replacement prelookup also avoids ordinary unfenced job reads while the same job owns a recovery barrier.

For an APPLYING checkpoint with its original freezing/prepared manifest, recovery finishes freezing and applies the original prepared templates under the new guard, checking existing receipts and committing only remaining chunks. A scoped heartbeat renews that guard during the local work. This path returns immediately after the same logical delta becomes complete; it does not invoke the extraction handler, provider, admission, regeneration or cleanup. Only the final original commit clears the barrier. Real completed workflow receipts retain the existing idempotent statistics observation. This fixes the demonstrated pre-admission STATE_PAGE_FAILED loop that prevented acquisition and left delta11/chunk46 unchanged after lease expiry.

Terminal regeneration reserves a private root/child identity; it does not itself create a child row in mem:graph:jobs. Normal TS initial capture materializes that child. Absence of a child is not evidence of non-dispatch or permission to repeat an old request.

Cached terminal links now reconcile the same root through native status before continuation. An expired unclaimed reservation becomes the native SLOT_EXHAUSTED terminal, retained with its historical child identity and action none. It cannot remain an endlessly actionable cached link. Claimed children keep their own native capture/exhaustion checks; a valid complete capture remains locally reusable. No deadline, admission, token, root or spent counter is reset.

Initial and resumed terminal delivery use the same durable intent and existing delivery identity directly through the existing deliver path, rather than depending on a publication ACK followed by a ten-minute blind claim wait. The first local claim is capped by the original native reservation deadline. A failed local delivery retains that identity and its bounded backoff; overlapping durable delivery is serialized by the same intent lock and revalidates native state. Only a fresh native Prepare/Dispatch acknowledgement can cause a raw provider call. Later untouched units preserve their ordinary durable continuation. The terminal record retains the actual dispatchIntentId returned by intake for subsequent evidence without reconstructing arguments.

Observed v7 evidence established a real reservation with no materialized child. It did not establish the exact original publication failure. Safe diagnostics now identify fixed get/set/get_versioned/list_page/scope_revision/durable-publish boundaries as well as storage, and deferred delivery logs contain only IDs and fixed code/class fields. The already-expired original reservation remains terminal; this correction does not claim that incident recovered or create another permission for it.

Authority profiles and request bindings use the method-qualified canonical endpoint POST plus the exact serializer URL, as required by both bridge and native contracts. The raw fetch still uses the unchanged serializer URL and an explicit POST. The builder rejects noncanonical URLs, credentials, query/fragment or unsupported protocols before installing a declaration.

Normal startup can retire only the exact invalid URL-only predecessor of a current real OpenAI builder declaration: identical complete declaration except the missing POST prefix, with its own original content-addressed v1 ID recomputed algorithmically. Such a profile could never pass native validation or pin. Every valid, pinned or unknown profile remains untouched. Before the one-time replacement, startup writes a private exclusive synced graph-automatic-authority.before-invalid-endpoint-v1.json beforeimage; an existing differing beforeimage fails closed. The corrected declaration receives its own new ID. This migration changes no native grant, slot, request history, root budget or credentials. Private temporary ACLs are validated while the file is still empty, before writing its authority body.

Graph failure diagnostics preserve an explicit allowlist of native automatic-recovery rejection codes only for SDK errors attributed to state::storage. They retain safe stateFunction/transportCode/failureKind fields. A bounded message inspection extracts only a code present in that allowlist; no raw error, native request, source or response text is logged. This prevents a native rejection from being flattened to GRAPH_EXECUTION_FAILED. It changes diagnostic evidence, not admissions, retries, cleanup ownership or the original failed-intent policy. Terminal discovery still requires a genuinely stopped job; a failed job with recoveryStopped=false remains in its existing bounded recovery path until its real disposition settles.

The Windows privacy helper uses the Windows system PowerShell executable and explicitly imports its own built-in Management/Security manifests from PSHOME. Only that child receives an isolated built-in PSModulePath, excluding a parent PowerShell7 module search path; host configuration/environment is unchanged. Command auto-loading is disabled and Get-Item/Get-Acl are module-qualified. A caught helper error emits only a fixed helperClass: module_load, command_unavailable, parser, descriptor, acl_read or unknown. Node exposes that allowlisted class with script_exit, never raw subprocess stderr. This addresses the concrete cross-version module-search boundary while leaving the exact observed failure's root cause unproven until normal startup supplies the class.

Windows bootstrap diagnostics distinguish phase (directory, previous_file, temporary_file, parent) and failure (canonical, file_type, owner_or_mode, acl_policy, script_launch, script_exit, timeout, filesystem). These fixed fields are exposed as optional graphAutomaticAvailability.diagnostic and in the safe startup warning. A PowerShell launch/exit/timeout is authorization unavailable, not evidence that the ACL itself is unsafe. Policy exit2 remains a privacy rejection; no ACL requirement is weakened. Paths, scripts, stderr and credentials are excluded from diagnostics.

Each fresh acknowledged dispatch writes graph-provider-usage:v1:{nativeAttemptId} in existing KV.state before the raw effect. Its permanent 64-hex effect key derives from that attempt identity. A missing ACK or interrupted effect means potential dispatch, not a confirmed API call. Complete raw captures record only actual API-reported token fields, their native capture digest and optional response model before decoding graph content. Missing usage remains unknown or partial; no zero tokens or billed dollars are fabricated. costUsd remains null because this path has no actual billing-price evidence.

Known input/output usage invokes the existing task-router/index MetricsStore callback with that permanent effect key. Capture reuse cannot count another expense, including replay after a lost metrics ACK. Unknown/partial events do not increment the successful usage aggregate. The processingUsage feed carries nativeAttemptId, nativeCaptureDigest, dispatchState, usageState and costUsd so coverage/unreported outcomes remain distinguishable from measured API tokens. Its same-ID enriched event supersedes the basic aggregate event when readers deduplicate. A durable projection queue retries at most four entries during normal graph recovery; unavailable statistics never cause another provider call. Historical local replay does not invent usage for an old attempt that lacks an actual request binding.

## Activation and rollback

Main must emit/install final native source54 (graphbuild identities, terminal extra-attempt settlement, retry_after_ms, terminal_recover and local delivery/source lineage proof) together with this application source, align State directory/private ACL and start the ordinary service. Authority is derived during awaited startup, not manually installed for a case. This worker ran no provider calls, live State operations, restarts, builds, tests, typecheck, checksums, artifact reviews or health probes. Build and live behavior are unverified.

Rollback disables the new workflow first and retains authority declarations, native tables, captures, root links, clock, counters and original unknown evidence. Never reset spent state. Source53 invocation/failure statistics and source55 publication/projection were preserved.
