# AgentMemory 0.9.83

Operators can pause startup indexed-source repair and vector backfill, plus periodic summary recovery, graph recovery, and terminal retention, with `AGENTMEMORY_BACKGROUND_RECOVERY_PAUSED=1`. The pause is off by default.

This release repairs snapshot and export on SQLite V2 databases containing graph records larger than the native 1 MiB page budget. Snapshot enumerates projected IDs, reads every record individually, and writes JSON with backpressure before publishing the file. Export offers collection pages with bounded projected-ID reads, point gets, and opaque cursors. Native revision metadata guards each page and invalidates continuation after a collection changes; it does not hash every record. The exact total is returned only on the final page, and callers must follow every cursor, including empty observation pages with `hasMore: true`.

Terminal graph jobs now close atomically with bounded physical cleanup. A guarded continuation can prune eligible historical terminal staging and audit rows without deleting observations, graph records, configuration, or retained replay receipts. Ineligible jobs remain untouched. New audit writes are disabled; historical queries remain available. The viewer timeline displays the most recent 20 operations.

Startup can repair a bounded set of interrupted semantic index writes with the configured local embedding provider before enforcing full index readiness. Source identity and graph checks remain strict; a larger gap still stops with an explicit error. Forgetting an observation or session also removes its access log, including the temporary observation used by live recall acceptance.
