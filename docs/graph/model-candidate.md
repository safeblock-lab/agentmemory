# Local multilingual reranker candidate

Production retains `Xenova/ms-marco-MiniLM-L-6-v2` and 128 semantic probes. The optional calibration candidate combines 256 probes with `onnx-community/bge-reranker-v2-m3-ONNX` revision `90213ffc6a8e6f051a6331269a0f5526cdd896f6`, CPU q8. It uses a single raw scalar relevance logit, at most 512 paired tokens, a 50-document scoring window, one CPU thread and eight queued batches. Candidate configuration must precede runtime loading and vector construction.

`eval/local-indexed/candidate-model.json` supplements the unchanged original freeze. The campaign checks the original freeze and baseline asset manifest, the unchanged embedding identity and cached bytes, all seven BGE assets, provisioning manifest, native executable and native source pins. It verifies those inputs and the application/harness fingerprint again after scoring. Candidate assets use absolute local paths with `local_files_only`; no remote fallback or global environment change is needed.

Main must separately accept the complete native suite and the preparatory sidecar/harness before any model load, including the single synthetic pair. Main owns `inference-accepted.json` under `.native-pagination-build/semantic-quality-correction/combined-bge256`, with `nativeSuiteAccepted`, `sidecarHarnessAccepted`, `candidateSidecarSha256` and `runtimeSha256`. This gate authorizes the exact local candidate only. The prepared runner accepts `preflight` or `campaign`; the campaign also requires the successful exact preflight and creates an exclusive claim that prevents retries.

The sole additional calibration campaign contains 54 queries in five chunks of 12/12/12/12/6, with a 10-minute deadline per chunk and 60-minute overall deadline. Its paired-score upper bound is 5,616 plus one synthetic preflight pair. It compares final ranking with the same BGE exhaustive scorer and verifies unchanged stored vectors before and after every chunk. All frozen quality, query time, sampled combined RSS and exact graph parity gates apply; failure consumes the campaign and prevents adoption. Resource and cleanup failures invalidate the result.

This is preparation, not quality acceptance. Held-out queries and judgements remain sealed for a separately authorized package freeze. Labels are synthetic agent-authored judgments, not an independent human oracle. A previous helper displayed one held-out corpus line; that incident does not authorize further held-out access. Historical failures and the retained trace remain unchanged.

Rollback uses exact original file copies and their hashes in `combined-bge256/baseline.json`; restore only changed owned paths after checking current hashes and preserving unrelated work. Native artifacts, native acceptance pointers and original frozen files are read-only to the semantic worker.
